```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def covid_forecast(train_values, horizon, **kwargs):
    """
    Forecast COVID-19 incidence data using a SARIMAX model.
    
    Args:
        train_values (np.ndarray): Training data of shape (T, N).
        horizon (int): Number of future time steps to forecast.
        
    Returns:
        np.ndarray: Forecasted values of shape (horizon, N).
    """
    # Initialize forecasts array
    forecasts = np.zeros((horizon, train_values.shape[1]))
    
    # Fit SARIMAX model on each region
    for region in range(train_values.shape[1]):
        try:
            model = SARIMAX(train_values[:, region], order=(1, 1, 1), seasonal_order=(1, 1, 1, 7))
            fitted_model = model.fit(disp=False)
            forecast = fitted_model.forecast(steps=horizon)
            forecasts[:, region] = forecast.clip(0)  # Clip negative values to zero
        except Exception as e:
            warnings.warn(f"Failed to fit SARIMAX model for region {region}: {e}")
            forecasts[:, region] = np.nan  # Set failed forecasts to NaN
    
    return forecasts
```

This implementation uses a Seasonal AutoRegressive Integrated Moving Average with eXogenous factors (SARIMAX) model to forecast COVID-19 incidence data. The model is applied to each geographical region independently. The `order` parameter specifies the ARIMA component, and `seasonal_order` accounts for seasonal effects with a weekly cycle. Forecasts are clipped to zero to handle negative predictions. If a model fails to fit, the corresponding region's forecasts are set to NaN.
