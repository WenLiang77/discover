```python
import numpy as np
from statsmodels.tsa.arima.model import ARIMA

def covid_forecast(train_values, horizon, **kwargs):
    """
    Forecast COVID-19 incidence data using an ARIMA model.
    
    Parameters:
    train_values (np.array): A 2D array of shape (T, N) containing historical incidence data.
    horizon (int): The number of future time steps to forecast.
    **kwargs: Additional keyword arguments (not used).
    
    Returns:
    np.array: A 2D array of shape (horizon, N) containing the forecasted incidence data.
    """
    # Initialize the forecast array with zeros
    forecast = np.zeros((horizon, train_values.shape[1]))
    
    # Fit an ARIMA model to each region's data and make forecasts
    for i in range(train_values.shape[1]):
        try:
            model = ARIMA(train_values[:, i], order=(5,1,0))  # Adjust the order as needed
            model_fit = model.fit()
            forecast[:, i] = model_fit.forecast(steps=horizon)
        except Exception as e:
            # If fitting fails, use a simple moving average as a fallback
            ma_value = np.mean(train_values[:, i])
            forecast[:, i] = ma_value
    
    # Ensure non-finite values are sanitized and negative predictions are clipped to zero
    forecast[np.isinf(forecast)] = np.nanmean(forecast)
    forecast[np.isnan(forecast)] = 0
    forecast[forecast < 0] = 0
    
    return forecast
```

This implementation uses the ARIMA model from the `statsmodels` library to forecast COVID-19 incidence data. It fits an ARIMA model to each region's historical data and makes forecasts for the specified horizon. If fitting the ARIMA model fails for any region, it falls back to a simple moving average. Non-finite and negative predictions are sanitized to ensure the output is valid.
