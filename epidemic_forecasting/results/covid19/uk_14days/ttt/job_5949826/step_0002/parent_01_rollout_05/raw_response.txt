```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def covid_forecast(train_values, horizon, **kwargs):
    forecasted_values = np.zeros((horizon, train_values.shape[1]))
    for region in range(train_values.shape[1]):
        region_data = train_values[:, region]
        try:
            # Fit a SARIMAX model to the data
            model = SARIMAX(region_data, order=(1, 1, 1), seasonal_order=(1, 1, 1, 7))
            fitted_model = model.fit(disp=False)
            forecast = fitted_model.get_forecast(steps=horizon).predicted_mean
            forecasted_values[:, region] = np.maximum(forecast, 0)
        except Exception as e:
            forecasted_values[:, region] = 0
    return forecasted_values
```

This implementation uses a SARIMAX model, which is suitable for handling both trend and seasonality in the data. The parameters `(1, 1, 1)` for the ARIMA part and `(1, 1, 1, 7)` for the seasonal part are chosen based on common defaults, but they can be tuned further for better performance. The model is fit without displaying the optimization progress (`disp=False`). The forecasted values are then clipped to zero to ensure non-negativity. If the model fitting fails, the function falls back to returning zeros for that region.
