```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def covid_forecast(train_values, horizon, **kwargs):
    """
    A simple SARIMA-based forecasting model for multivariate COVID-19 incidence data.
    
    Parameters:
        train_values (np.ndarray): Historical training data with shape (T, N).
        horizon (int): Number of future time steps to predict.
        kwargs: Additional keyword arguments (not used in this implementation).
        
    Returns:
        np.ndarray: Predicted values with shape (horizon, N).
    """
    
    # Initialize the forecasted values array
    forecast = np.zeros((horizon, train_values.shape[1]))
    
    # Fit a SARIMA model for each region
    for i in range(train_values.shape[1]):
        try:
            # Fit the SARIMA model
            model = SARIMAX(train_values[:, i], order=(1, 1, 1), seasonal_order=(1, 1, 1, 7))
            result = model.fit(disp=False)
            
            # Forecast the next 'horizon' steps
            forecast[:horizon, i] = result.forecast(steps=horizon)
            
            # Ensure non-negative values
            forecast[:horizon, i] = np.maximum(forecast[:horizon, i], 0)
            
        except Exception as e:
            # If fitting fails, fill the forecast with zeros
            print(f"Failed to fit model for region {i}: {e}")
            forecast[:horizon, i] = 0
    
    return forecast
```

This implementation fits a SARIMA model to each region's historical data and forecasts the next `horizon` steps. If fitting a model fails for any region, it handles the exception by filling the forecast for that region with zeros. This ensures that the output always has the correct shape and contains only finite, non-negative values.
