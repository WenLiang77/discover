```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def covid_forecast(train_values, horizon, **kwargs):
    # Initialize an empty list to store forecasts for each region
    forecasts = []
    
    # Iterate over each region
    for i in range(train_values.shape[1]):
        # Extract the time series for the current region
        region_series = train_values[:, i]
        
        # Fit a SARIMAX model to the time series data
        try:
            model = SARIMAX(region_series, order=(1, 1, 1), seasonal_order=(0, 1, 0, 7))
            fitted_model = model.fit(disp=False)
        except Exception as e:
            # If fitting fails, use a simple exponential smoothing
            alpha = 0.1
            forecast = [np.mean(region_series)] * (horizon + len(region_series))
            for t in range(len(region_series), len(region_series) + horizon):
                forecast[t] = alpha * region_series[-1] + (1 - alpha) * forecast[t-1]
            forecasts.append(np.clip(forecast[len(region_series):], 0, None))
            continue
        
        # Generate forecasts for the specified horizon
        forecast = fitted_model.forecast(steps=horizon)
        forecasts.append(np.clip(forecast, 0, None))
    
    # Convert the list of forecasts to a numpy array
    return np.array(forecasts).T
```

This implementation uses the SARIMAX model from the `statsmodels` library to fit a time series model to each region's data. If fitting the model fails due to issues like non-stationarity or insufficient data, it falls back to simple exponential smoothing. The forecasts are then clipped to ensure they are non-negative before being returned.
