```python
import numpy as np
from statsmodels.tsa.holtwinters import ExponentialSmoothing

def covid_forecast(train_values, horizon, **kwargs):
    """
    Forecast COVID-19 incidence using Holt-Winters exponential smoothing
    
    Parameters:
        train_values (np.ndarray): Historical incidence data with shape (T, N)
        horizon (int): Number of future time steps to predict
        
    Returns:
        np.ndarray: Forecasted incidence data with shape (horizon, N)
    """
    forecasted = np.zeros((horizon, train_values.shape[1]))
    
    # Fit and forecast each region independently
    for i in range(train_values.shape[1]):
        try:
            # Fit Holt-Winters model
            model = ExponentialSmoothing(train_values[:, i], trend='add', seasonal=None).fit()
            
            # Forecast
            forecast = model.forecast(steps=horizon)
            forecasted[:, i] = forecast.clip(0)
        except Exception as e:
            # If fitting fails, use a simple moving average as a fallback
            moving_avg = np.convolve(train_values[:, i], np.ones(horizon), mode='valid') / horizon
            forecasted[:len(moving_avg), i] = moving_avg
            if len(moving_avg) < horizon:
                forecasted[len(moving_avg):, i] = moving_avg[-1]
    
    return forecasted
```

This implementation uses the Holt-Winters exponential smoothing model to forecast each geographical region's COVID-19 incidence independently. If the fitting process encounters any errors (e.g., due to insufficient data or poor model assumptions), it falls back to a simple moving average. This ensures robustness even when individual regions have challenging characteristics.
