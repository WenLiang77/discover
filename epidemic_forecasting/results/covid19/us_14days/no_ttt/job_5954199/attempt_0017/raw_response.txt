```python
import numpy as np
from statsmodels.tsa.holtwinters import ExponentialSmoothing

def covid_forecast(train_values, horizon, **kwargs):
    """
    Forecast COVID-19 incidence data using exponential smoothing.

    Parameters:
    train_values (np.ndarray): Training data of shape (T, N).
    horizon (int): Number of future time steps to predict.
    kwargs: Additional keyword arguments (not used).

    Returns:
    np.ndarray: Forecasted values of shape (horizon, N).
    """
    # Initialize the forecasted array
    forecasts = np.zeros((horizon, train_values.shape[1]))
    
    # Apply exponential smoothing to each region
    for i in range(train_values.shape[1]):
        try:
            # Fit the Holt-Winters model
            model = ExponentialSmoothing(train_values[:, i], trend='add', seasonal=None)
            fitted_model = model.fit(disp=False)
            
            # Predict the next 'horizon' steps
            forecast = fitted_model.forecast(horizon)
            forecasts[:, i] = forecast
        except Exception as e:
            # If fitting fails, fill with zeros (safety measure)
            forecasts[:, i] = 0
    
    # Ensure all values are non-negative
    forecasts = np.maximum(forecasts, 0)
    
    return forecasts
```

This implementation uses exponential smoothing to forecast COVID-19 incidence data for multiple regions. The `ExponentialSmoothing` class from `statsmodels.tsa.holtwinters` is used to fit a model to each region's historical data. The model is then used to predict the next `horizon` time steps. If fitting the model fails for any region, the forecast is filled with zeros as a safety measure. Finally, all predicted values are sanitized to ensure they are non-negative.
