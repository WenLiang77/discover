```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from statsmodels.tsa.statespace.sarimax import SARIMAX

def covid_forecast(train_values, horizon, **kwargs):
    # Initialize the scaler
    scaler = StandardScaler()
    
    # Scale the training data
    scaled_train_values = scaler.fit_transform(train_values)
    
    # Fit a SARIMA model for each region
    forecast_results = []
    for i in range(scaled_train_values.shape[1]):
        try:
            # Fit a SARIMA model
            model = SARIMAX(scaled_train_values[:, i], order=(1, 1, 1), seasonal_order=(1, 1, 1, 24))
            fitted_model = model.fit(disp=False)
            
            # Forecast the next 'horizon' time steps
            forecast = fitted_model.get_forecast(steps=horizon)
            forecast_values = forecast.predicted_mean
            
            # Inverse transform the forecasted values
            inverse_forecast = scaler.inverse_transform(forecast_values.reshape(-1, 1))[:, 0]
            
            # Ensure non-negative values
            inverse_forecast = np.maximum(inverse_forecast, 0)
            
            forecast_results.append(inverse_forecast)
        except Exception as e:
            # Handle fitting failures by returning zeros
            forecast_results.append(np.zeros(horizon))
    
    # Return the forecast results as a NumPy array
    return np.array(forecast_results).T
```

This implementation uses a SARIMAX model for each region to forecast the next `horizon` time steps. The data is scaled using `StandardScaler` before fitting the model and then inversely transformed after forecasting. Non-negative values are ensured by clipping negative predictions to zero. If a model fitting fails, the function returns zeros for that region's forecasts.
