```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def covid_forecast(train_values, horizon, **kwargs):
    """
    A forecasting function for COVID-19 incidence data using SARIMAX model.
    
    Parameters:
    - train_values: A 2D NumPy array of shape (T, N) containing historical incidence data.
    - horizon: An integer representing the number of future time steps to predict.
    
    Returns:
    - A 2D NumPy array of shape (horizon, N) containing the forecasted incidence data.
    """
    # Initialize the forecasted values array
    forecasted_values = np.zeros((horizon, train_values.shape[1]))
    
    # Fit a SARIMAX model for each region
    for i in range(train_values.shape[1]):
        try:
            # Fit the SARIMAX model
            model = SARIMAX(train_values[:, i], order=(5, 1, 0), seasonal_order=(1, 1, 0, 7))
            fitted_model = model.fit(disp=False)
            
            # Forecast the next 'horizon' time steps
            forecast = fitted_model.forecast(steps=horizon)
            forecasted_values[:, i] = np.maximum(0, forecast)  # Clip negative predictions to zero
        except Exception as e:
            # If fitting fails, fill the forecast with zeros
            forecasted_values[:, i] = 0
    
    return forecasted_values
```

This implementation uses a SARIMAX model, which is suitable for time series with potential seasonal patterns and trends. The model is fit individually for each region, and forecasts are made using these fitted models. Non-finite values and negative predictions are sanitized by clipping them to zero. This approach ensures that the forecasted values are always valid and positive.
