```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.tsa.holtwinters import ExponentialSmoothing

def covid_forecast(train_values, horizon, **kwargs):
    forecasted_values = np.zeros((horizon, train_values.shape[1]))
    for region in range(train_values.shape[1]):
        region_data = train_values[:, region]
        region_data += 1e-06  # Add a small constant to avoid log(0) issues
        
        # Try fitting a SARIMAX model
        try:
            model = SARIMAX(region_data, order=(1, 1, 1), seasonal_order=(1, 1, 1, 7))
            fitted_model = model.fit(disp=False)
            forecast = fitted_model.get_forecast(steps=horizon).predicted_mean
        except Exception as _:
            # If SARIMAX fails, try fitting an Exponential Smoothing model
            try:
                model = ExponentialSmoothing(region_data, trend='add', seasonal=None)
                fitted_model = model.fit()
                forecast = fitted_model.forecast(steps=horizon)
            except Exception as _:
                # If both fail, use a simple average of the region's history
                forecast = np.full(horizon, np.mean(region_data))
        
        # Ensure all forecasts are non-negative
        forecasted_values[:, region] = np.maximum(forecast, 0)
    
    return forecasted_values
```

This implementation attempts to fit a SARIMAX model first, which can handle both trend and seasonal components. If that fails, it falls back to an Exponential Smoothing model, which is simpler and can handle non-stationary data well. If both models fail, it defaults to a simple average of the historical data for each region. This approach ensures robustness against various types of data characteristics while maintaining simplicity and efficiency.
