```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    """
    Forecast dengue incidence using SARIMAX models.
    
    Parameters:
    - train_values: np.array of shape (T, N), training data with T time steps and N regions.
    - horizon: int, number of future time steps to predict.
    
    Returns:
    - np.array of shape (horizon, N) containing predicted dengue incidences.
    """
    n_regions = train_values.shape[1]
    forecast_values = np.zeros((horizon, n_regions))
    
    for region in range(n_regions):
        # Fit SARIMAX model to the region's data
        try:
            model = SARIMAX(train_values[:, region], order=(1, 1, 0), seasonal_order=(1, 1, 0, 52))
            results = model.fit(disp=False)
            
            # Forecast for the specified horizon
            forecast = results.forecast(steps=horizon)
            forecast_values[:len(forecast), region] = np.maximum(0, forecast)
        except Exception as e:
            # Fallback to a simple average if model fitting fails
            avg_value = np.mean(train_values[:, region])
            forecast_values[:, region] = np.full(horizon, max(0, avg_value))
    
    return forecast_values
```

### Explanation:
1. **Model Selection**: We use the SARIMAX (Seasonal AutoRegressive Integrated Moving Average with eXogenous factors) model from the `statsmodels` library. This model is suitable for time-series with potential seasonal patterns.

2. **Fitting the Model**: For each region, we fit a SARIMAX model to the historical data. The parameters `(1, 1, 0)` for the ARIMA part and `(1, 1, 0, 52)` for the seasonal part are chosen based on common practices for weekly data with annual seasonality.

3. **Forecasting**: After fitting the model, we forecast the next `horizon` steps. If there is an exception during the fitting process (e.g., due to insufficient data or structural issues), we catch the exception and fall back to a simple average of the historical data for that region.

4. **Non-Negative Forecasts**: Since dengue incidence cannot be negative, we ensure all forecasts are non-negative by taking the maximum between the forecasted value and 0.

This approach ensures that the model captures temporal dependencies and seasonal effects while providing a robust fallback mechanism in cases where the model fitting fails.
