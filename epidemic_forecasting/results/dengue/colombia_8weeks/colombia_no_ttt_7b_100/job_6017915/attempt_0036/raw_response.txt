```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline

def dengue_forecast(train_values, horizon, random_state=None):
    n_regions = train_values.shape[1]
    forecast = np.zeros((horizon, n_regions))
    
    for region in range(n_regions):
        # Fit a polynomial regression model to each region's time series
        X = np.arange(train_values.shape[0]).reshape(-1, 1)
        y = train_values[:, region]
        
        # Create a pipeline with PolynomialFeatures and LinearRegression
        model = make_pipeline(PolynomialFeatures(degree=2), LinearRegression())
        model.fit(X, y)
        
        # Predict the next 'horizon' steps
        future_X = np.arange(len(y), len(y) + horizon).reshape(-1, 1)
        future_y = model.predict(future_X)
        
        # Ensure the forecast is non-negative
        forecast[:, region] = np.maximum(future_y, 0)
    
    return forecast
```

This implementation fits a polynomial regression model to each region's time series and uses it to predict the next `horizon` steps. The polynomial features help capture temporal evolution, and the forecast is clamped to non-negative values to meet the problem requirements.
