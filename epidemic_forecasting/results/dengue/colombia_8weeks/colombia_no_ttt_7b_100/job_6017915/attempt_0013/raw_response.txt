```python
import numpy as np
from statsmodels.tsa.arima.model import ARIMA

def dengue_forecast(train_values, horizon, **kwargs):
    n_regions = train_values.shape[1]
    forecast = np.zeros((horizon, n_regions))
    
    for i in range(n_regions):
        try:
            # Fit an ARIMA model to each region's data
            model = ARIMA(train_values[:, i], order=(5,1,0))
            model_fit = model.fit()
            
            # Forecast the next 'horizon' steps
            forecast[:, i] = model_fit.forecast(steps=horizon)
        except Exception as e:
            # If fitting fails, return zeros for that region
            pass
    
    # Ensure all predictions are non-negative
    forecast = np.maximum(forecast, 0)
    
    return forecast
```

This implementation fits an ARIMA model to each region's historical data and then forecasts the next `horizon` steps. If fitting the model fails for any reason (e.g., due to insufficient data), the function returns zeros for that region. This ensures that the forecast remains non-negative and conforms to the required shape.
