```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from sklearn.preprocessing import PowerTransformer

def dengue_forecast(train_values, horizon, random_state=None):
    # Initialize the forecast result with zeros
    forecasts = np.zeros((horizon, train_values.shape[1]))
    
    # Define the SARIMA model parameters
    order = (1, 1, 1)
    seasonal_order = (1, 1, 1, 52)  # Assuming weekly data
    
    # Loop through each region
    for i in range(train_values.shape[1]):
        # Apply power transformation to stabilize variance
        pt = PowerTransformer(method='yeo-johnson')
        transformed_data = pt.fit_transform(train_values[:, [i]])
        
        try:
            # Fit SARIMAX model
            model = SARIMAX(transformed_data.flatten(), order=order, seasonal_order=seasonal_order, enforce_stationarity=False, enforce_invertibility=False)
            model_fit = model.fit(disp=False)
            
            # Generate forecast for the region
            forecast_steps = model_fit.forecast(steps=horizon)
            forecast_steps = pt.inverse_transform(forecast_steps.reshape(-1, 1)).flatten()
            
            # Ensure non-negative forecast
            forecasts[:, i] = np.maximum(forecast_steps, 0)
        except Exception as e:
            # If fitting fails, use a simple moving average as a fallback
            window_size = min(10, train_values.shape[0])
            rolling_mean = np.convolve(train_values[:, i], np.ones(window_size)/window_size, mode='valid')
            forecast_steps = np.full(horizon, rolling_mean[-1]) if len(rolling_mean) > 0 else np.zeros(horizon)
            forecasts[:, i] = np.maximum(forecast_steps, 0)
    
    return forecasts
```

This implementation uses a SARIMAX model from `statsmodels` to fit the historical data for each region and generates forecasts. The data is transformed using the Yeo-Johnson power transform to stabilize variance. If the model fitting fails, a simple moving average is used as a fallback. The forecast is ensured to be non-negative. This approach aims to capture temporal evolution while handling potential issues with model fitting and ensuring the forecast is reliable and non-negative.
