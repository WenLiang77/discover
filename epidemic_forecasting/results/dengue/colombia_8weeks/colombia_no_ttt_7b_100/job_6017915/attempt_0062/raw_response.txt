```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.tools.eval_measures import smape, mae, rmse, mase

def dengue_forecast(train_values, horizon, **kwargs):
    n_regions = train_values.shape[1]
    forecasted_values = np.zeros((horizon, n_regions))
    
    for region in range(n_regions):
        try:
            # Fit a SARIMAX model to the historical data for each region
            model = SARIMAX(train_values[:, region], order=(2, 0, 1), seasonal_order=(1, 0, 1, 52))
            results = model.fit(disp=False)
            
            # Forecast the next 'horizon' weeks
            forecast = results.forecast(steps=horizon)
            forecasted_values[:, region] = forecast
        except Exception as e:
            # If fitting fails, use a simple moving average as a fallback
            window_size = min(10, len(train_values[:, region]))
            smoothed_values = np.convolve(train_values[:, region], np.ones(window_size)/window_size, mode='valid')
            forecasted_values[:len(smoothed_values), region] = smoothed_values
            forecasted_values[len(smoothed_values):, region] = np.mean(train_values[:, region])
    
    # Ensure all forecasted values are non-negative
    forecasted_values = np.maximum(forecasted_values, 0)
    
    return forecasted_values
```

This implementation uses the SARIMAX model from the `statsmodels` library to fit a time-series model to each region's historical data and then forecasts the next `horizon` weeks. If fitting the model fails for any reason, a simple moving average is used as a fallback. The forecasted values are then clipped to ensure they are non-negative. This approach aims to model temporal evolution while handling potential issues gracefully.
