```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import matplotlib.pyplot as plt

def dengue_forecast(train_values, horizon, **kwargs):
    """
    Forecasts dengue incidence using a SARIMAX model for each region.

    Args:
        train_values: A NumPy array of shape (T, N) containing historical
                      dengue incidence data.
        horizon: An integer indicating the number of future time steps to predict.

    Returns:
        A NumPy array of shape (horizon, N) containing the predicted dengue
        incidence values.
    """
    num_regions = train_values.shape[1]
    predictions = np.zeros((horizon, num_regions))

    # Fit a SARIMAX model for each region
    for i in range(num_regions):
        try:
            model = SARIMAX(train_values[:, i], order=(1, 1, 1), seasonal_order=(0, 1, 1, 52))
            model_fit = model.fit(disp=False)
            
            # Forecast the next 'horizon' time steps
            forecast_result = model_fit.get_forecast(steps=horizon)
            forecast = forecast_result.predicted_mean
            
            # Ensure non-negative predictions
            forecast = np.maximum(forecast, 0)
            
            predictions[:, i] = forecast
        except Exception as e:
            # Fallback to a simple moving average if model fitting fails
            window_size = min(10, len(train_values))
            rolling_avg = np.convolve(train_values[:, i], np.ones(window_size)/window_size, mode='valid')
            padding = np.full(horizon - len(rolling_avg), rolling_avg[-1])
            fallback_predictions = np.concatenate((rolling_avg, padding))
            predictions[:, i] = fallback_predictions
    
    return predictions
```

### Explanation:
This forecasting algorithm uses a Seasonal AutoRegressive Integrated Moving Average with eXogenous factors (SARIMAX) model for each region. The SARIMAX model is suitable for time series with both trend and seasonality components. Here's how the code works:

1. **Model Fitting**: For each region, a SARIMAX model is fitted to the historical data. The parameters `(1, 1, 1)` for the ARIMA part and `(0, 1, 1, 52)` for the seasonal part are chosen based on common defaults for dengue forecasting. The seasonality parameter `52` assumes a yearly seasonality pattern.

2. **Forecasting**: Once the model is fitted, it is used to forecast the next `horizon` time steps.

3. **Non-Negative Constraint**: To ensure the forecasts are non-negative, any negative values are clipped to zero.

4. **Fallback Mechanism**: If the model fitting process encounters any issues (e.g., convergence problems), the algorithm falls back to a simple moving average forecast. This ensures that even if the model fails, there is at least some valid forecast produced.

5. **Handling Sparse Data**: The moving average fallback helps handle sparse or very short time series data by providing a reasonable estimate based on past data.

6. **Shape Enforcement**: The function ensures that the output array has the correct shape `(horizon, N)`.

This approach aims to provide a robust and flexible forecasting solution that handles various types of time series data while ensuring non-negative predictions.
