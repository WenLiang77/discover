```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    # Ensure train_values is a NumPy array
    train_values = np.array(train_values)
    
    # Get the number of time steps and regions
    T, N = train_values.shape
    
    # Initialize the forecast array
    forecast = np.zeros((horizon, N))
    
    # Fit a SARIMAX model for each region
    for region in range(N):
        try:
            # Fit a SARIMAX model to the historical data for the current region
            model = SARIMAX(train_values[:, region], order=(1, 1, 0), seasonal_order=(1, 1, 0, 52))
            results = model.fit(disp=False)
            
            # Generate the forecast for the current region
            forecast[:, region] = results.forecast(steps=horizon)
        except Exception as e:
            # If fitting fails, use a simple exponential smoothing fallback
            alpha = 0.1
            smoothed_series = np.convolve(train_values[:, region], [alpha] * 4 + [1 - alpha * (4 + 1)], mode='valid')
            forecast[:len(smoothed_series), region] = smoothed_series
            forecast[len(smoothed_series):, region] = smoothed_series[-1]
    
    # Clip negative predictions to zero
    forecast[forecast < 0] = 0
    
    return forecast
```

This forecasting algorithm uses the SARIMAX model from the `statsmodels` library to fit a time-series model to each region's historical dengue case-count data. The SARIMAX model is capable of capturing both trend and seasonal components, which are important features in time-series forecasting. For regions where fitting the SARIMAX model fails (e.g., due to insufficient data or other issues), a simple exponential smoothing fallback is used. The forecast is then clipped to ensure that all predicted values are non-negative.
