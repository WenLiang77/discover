```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    # Define parameters for SARIMAX model
    order = (1, 1, 1)
    seasonal_order = (1, 1, 1, 52)
    
    num_regions = train_values.shape[1]
    forecast_horizon = horizon
    
    # Initialize an array to store the forecasts
    forecasts = np.zeros((forecast_horizon, num_regions))
    
    for i in range(num_regions):
        # Extract the time series for the current region
        region_series = train_values[:, i]
        
        try:
            # Fit the SARIMAX model to the historical data
            model = SARIMAX(region_series, order=order, seasonal_order=seasonal_order)
            results = model.fit(disp=False)
            
            # Generate the forecast for the specified horizon
            forecast = results.get_forecast(steps=forecast_horizon).predicted_mean
            
            # Ensure non-negative forecasts
            forecast = np.maximum(forecast, 0)
            
            # Store the forecast for the current region
            forecasts[:, i] = forecast
        except Exception as e:
            # If fitting fails, use a simple moving average as a fallback
            moving_avg = np.convolve(region_series, np.ones(forecast_horizon)/forecast_horizon, mode='valid')
            forecast = np.pad(moving_avg, (0, forecast_horizon - len(moving_avg)), 'constant', constant_values=(moving_avg[-1], 0))
            forecast = np.maximum(forecast, 0)
            forecasts[:, i] = forecast
    
    return forecasts
```

This implementation uses a Seasonal AutoRegressive Integrated Moving Average with eXogenous factors (SARIMAX) model to forecast dengue cases for each region. The model is trained on the historical data for each region and then used to generate forecasts for the specified horizon. If the model fitting fails for a given region, a simple moving average is used as a fallback. The forecasts are ensured to be non-negative before being returned.
