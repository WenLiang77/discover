```python
import numpy as np
from statsmodels.tsa.arima.model import ARIMA
from sklearn.preprocessing import MinMaxScaler

def dengue_forecast(train_values, horizon, **kwargs):
    scaler = MinMaxScaler(feature_range=(0, 1))
    scaled_train = scaler.fit_transform(train_values)
    
    forecasts = []
    for i in range(scaled_train.shape[1]):
        region_data = scaled_train[:, i]
        try:
            model = ARIMA(region_data, order=(5, 1, 0))  # Adjust order based on data characteristics
            model_fit = model.fit()
            forecast = model_fit.forecast(steps=horizon)
            forecast = scaler.inverse_transform(forecast.reshape(-1, 1)).reshape(-1)
            forecast = np.clip(forecast, 0, None)
            forecasts.append(forecast)
        except Exception as e:
            # Fallback to simple average if model fails
            avg_value = np.mean(region_data[-10:]) if len(region_data) >= 10 else 0
            forecast = [avg_value] * horizon
            forecasts.append(forecast)
    
    return np.array(forecasts).transpose()
```

This implementation uses the ARIMA model from the `statsmodels` library to forecast each region's dengue cases independently. It scales the data using `MinMaxScaler` to ensure that the model operates on values between 0 and 1, which can improve convergence and stability. If the ARIMA model fails to fit (e.g., due to insufficient data), it falls back to a simple moving average of the last 10 observations (or 0 if there are fewer observations).

The forecasted values are then inverted using the inverse transform of the scaler and clipped to ensure they are non-negative. This approach ensures that the forecast has the required shape and adheres to the constraints provided.
