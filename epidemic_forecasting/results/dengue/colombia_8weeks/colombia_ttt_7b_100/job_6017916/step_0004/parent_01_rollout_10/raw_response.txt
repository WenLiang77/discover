```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    for i in range(train_values.shape[1]):
        try:
            # Fit a SARIMA model to each region's time series
            model = SARIMAX(train_values[:, i], order=(1, 1, 0), seasonal_order=(1, 1, 0, 4))
            results = model.fit(disp=False)
            forecast[:, i] = results.forecast(steps=horizon)
        except Exception as e:
            # If model fitting fails, use the last observed value for the region
            forecast[:, i] = train_values[-1, i]
    
    # Ensure the forecast is non-negative
    forecast = np.maximum(forecast, 0)
    
    return forecast
```

This implementation uses the SARIMAX model from the `statsmodels` library to fit a seasonal ARIMA model to each region's time series. The model parameters `(1, 1, 0)` and `(1, 1, 0, 4)` are chosen based on common practice for time series forecasting. If the model fitting process encounters an exception (e.g., due to insufficient data or other issues), the forecast for that region is set to the last observed value. Finally, the forecast is clipped to ensure all values are non-negative before being returned. This approach ensures that the forecast respects the temporal dynamics of the time series while handling potential fitting failures gracefully.
