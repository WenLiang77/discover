```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.holtwinters import ExponentialSmoothing
from scipy.stats import zscore

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    
    for i in range(train_values.shape[1]):
        try:
            # Check if the series is stationary or needs differencing
            diff_series = train_values[:, i].diff().dropna()
            if len(diff_series) == 0:
                continue
            
            # Fit different models and take the best one
            models = [
                ('SARIMAX', SARIMAX(train_values[:, i], order=(1, 1, 0), seasonal_order=(1, 1, 0, 4))),
                ('ARIMA', ARIMA(train_values[:, i], order=(1, 1, 0))),
                ('Exponential Smoothing', ExponentialSmoothing(train_values[:, i], trend='add', seasonal='mul', seasonal_periods=4))
            ]
            
            results = []
            for name, model in models:
                try:
                    fit_model = model.fit(disp=False)
                    forecast_step = fit_model.forecast(steps=horizon)
                    results.append((name, fit_model, forecast_step))
                except Exception as e:
                    continue
            
            if not results:
                forecast[:, i] = train_values[-1, i]
                continue
            
            # Select the model with the lowest AIC (Akaike Information Criterion)
            best_model, _, best_forecast = min(results, key=lambda x: x[1].aic)
            forecast[:, i] = best_forecast
        
        except Exception as e:
            forecast[:, i] = train_values[-1, i]
    
    forecast = np.maximum(forecast, 0)
    return forecast
```

### Explanation:

1. **Stationarity Check**: The code checks if the series is stationary by taking the difference of the series. If the differenced series is empty, it skips fitting any models for that region.

2. **Model Fitting**: Three different models (`SARIMAX`, `ARIMA`, and `Exponential Smoothing`) are fitted to each region's time series data. Each model is wrapped in a tuple along with the fitted model object and the forecasted values.

3. **Model Selection**: The models are compared based on their Akaike Information Criterion (AIC). The model with the lowest AIC is selected as the best model for forecasting.

4. **Handling Errors**: If any model fails to fit, the code continues to the next region, falling back to a simple copy of the most recent observation.

5. **Forecast Clipping**: The forecasted values are clipped to ensure they are non-negative before returning.

This approach ensures that the forecasting model is both flexible and robust, capable of handling various types of time series data while avoiding overfitting and producing sensible forecasts.
