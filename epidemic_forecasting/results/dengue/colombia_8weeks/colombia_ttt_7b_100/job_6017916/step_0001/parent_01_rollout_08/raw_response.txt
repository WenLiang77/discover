```python
import numpy as np
from statsmodels.tsa.arima.model import ARIMA
from sklearn.preprocessing import MinMaxScaler
from sklearn.linear_model import LinearRegression

def dengue_forecast(train_values, horizon, **kwargs):
    n_regions = train_values.shape[1]
    forecast = np.zeros((horizon, n_regions))
    
    for i in range(n_regions):
        # Scale the data to the range [0, 1] using Min-Max scaling
        scaler = MinMaxScaler()
        scaled_data = scaler.fit_transform(train_values[:, [i]])
        
        # Fit an ARIMA model to the scaled data
        model = ARIMA(scaled_data.flatten(), order=(5, 1, 0))
        model_fit = model.fit(disp=0)
        
        # Forecast the next 'horizon' steps
        forecast[:, i], _ = model_fit.forecast(steps=horizon)
        
        # Rescale the forecast back to the original scale
        forecast[:, i] = scaler.inverse_transform(forecast[:, i].reshape(-1, 1)).flatten()
        
        # Ensure the forecast is non-negative
        forecast[:, i] = np.maximum(forecast[:, i], 0)
    
    return forecast
```

This implementation uses an ARIMA model for each region to forecast the next `horizon` weeks of dengue cases. The data for each region is scaled using Min-Max scaling before being fit to an ARIMA model. The forecasted values are then rescaled back to the original scale and clipped to ensure they are non-negative. This approach ensures that the forecast models temporal evolution while maintaining non-negativity.
