```python
import numpy as np
from statsmodels.tsa.holtwinters import ExponentialSmoothing
from sklearn.preprocessing import MinMaxScaler

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    scaler = MinMaxScaler(feature_range=(0, 1))
    
    for i in range(train_values.shape[1]):
        try:
            # Scale the training data
            scaled_train = scaler.fit_transform(train_values[:, i].reshape(-1, 1))
            
            # Fit an exponential smoothing model
            model = ExponentialSmoothing(scaled_train.flatten(), seasonal_periods=52, trend='add', seasonal='add')
            results = model.fit(use_boxcox=True)
            
            # Forecast the next horizon steps
            scaled_forecast = results.forecast(steps=horizon).reshape(1, -1)
            
            # Inverse transform the forecast
            forecast[:, i] = scaler.inverse_transform(scaled_forecast)[0]
            
            # Ensure non-negative forecasts
            forecast[:, i] = np.maximum(forecast[:, i], 0)
        
        except Exception as e:
            # Fallback to a simple average if the model fails
            forecast[:, i] = np.full(horizon, np.mean(train_values[:, i][-5:], initial=0))
    
    return forecast
```

### Explanation:
1. **Scaling**: We use `MinMaxScaler` to scale the data between 0 and 1, which helps in stabilizing the variance and making the model more effective.
2. **Model Selection**: An `ExponentialSmoothing` model is chosen because it can handle trends and seasonality effectively, which are common in dengue case counts.
   - `seasonal_periods=52`: This assumes weekly data (52 weeks per year).
   - `trend='add'` and `seasonal='add'`: These parameters allow the model to capture additive trends and seasons.
3. **Forecasting**: The model is trained on the scaled data, and then used to forecast the next `horizon` steps. The forecasted values are then inverse-transformed back to the original scale.
4. **Fallback Mechanism**: If the model fails to fit, a simple average of the last 5 data points is used as a fallback forecast. This ensures that the forecast is at least non-negative.
5. **Non-Negative Forecasts**: The forecasted values are clipped to ensure they are non-negative.

This approach ensures that the forecast captures the temporal dynamics of the dengue case counts while maintaining non-negativity.
