```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from sklearn.preprocessing import StandardScaler

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    scaler = StandardScaler()
    
    for i in range(train_values.shape[1]):
        try:
            # Scale the training data
            scaled_train = scaler.fit_transform(train_values[:, i].reshape(-1, 1))
            
            # Fit a SARIMAX model
            model = SARIMAX(scaled_train, order=(1, 1, 0), seasonal_order=(1, 1, 0, 4))
            results = model.fit(disp=False)
            
            # Generate the forecast
            scaled_forecast = results.forecast(steps=horizon)
            forecast[:, i] = scaler.inverse_transform(scaled_forecast.reshape(-1, 1)).flatten()
            
            # Ensure the forecast is non-negative
            forecast[:, i] = np.maximum(forecast[:, i], 0)
        except Exception as e:
            # Fallback to a simple moving average if model fails
            window_size = min(10, len(train_values[:, i]))
            rolling_mean = np.convolve(train_values[:, i], np.ones(window_size)/window_size, mode='valid')
            forecast[:, i] = np.append(np.full(window_size - 1, rolling_mean[0]), rolling_mean)
            forecast[:, i] = np.maximum(forecast[:, i], 0)
    
    return forecast
```

This implementation uses a SARIMAX model to fit each region's time series data and generate forecasts. If the model fitting fails, it falls back to a simple moving average. This ensures that the forecast is non-negative and has the required shape. The model parameters (order and seasonal_order) are chosen based on common practices for weekly data.
