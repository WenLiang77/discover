```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from sklearn.preprocessing import StandardScaler

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    scaler = StandardScaler()
    for i in range(train_values.shape[1]):
        try:
            # Scale the training data
            scaled_train = scaler.fit_transform(train_values[:, i].reshape(-1, 1))
            
            # Fit SARIMAX model
            model = SARIMAX(scaled_train, order=(1, 1, 0), seasonal_order=(1, 1, 0, 4))
            results = model.fit(disp=False)
            
            # Forecast scaled values
            scaled_forecast = results.forecast(steps=horizon)
            
            # Inverse transform to original scale
            forecast[:, i] = scaler.inverse_transform(scaled_forecast.reshape(-1, 1)).flatten()
            
            # Ensure non-negative forecasts
            forecast[:, i] = np.maximum(forecast[:, i], 0)
        except Exception as e:
            # Fallback to a simple moving average if model fails
            forecast[:, i] = np.convolve(train_values[:, i], np.ones(horizon)/horizon, mode='valid')
            forecast[:, i] = np.pad(forecast[:, i], (0, horizon - len(forecast[:, i])), mode='edge')
    
    return forecast
```

### Explanation:
1. **Scaling**: The data for each region is scaled using `StandardScaler` to ensure that the model can handle variations in scales effectively.
2. **SARIMAX Model**: A SARIMAX model is fitted to the scaled data. This model accounts for both trend and seasonality, which are common in dengue incidence data.
3. **Forecasting**: The model is used to forecast future values, which are then inverse-transformed back to the original scale.
4. **Non-Negative Forecasts**: To ensure that the forecasts are non-negative, we use `np.maximum(forecast[:, i], 0)`.
5. **Fallback Mechanism**: If the model fitting fails, a simple moving average is used as a fallback to ensure that the forecast has the correct shape and is non-negative.

This approach ensures that the forecast models temporal evolution and handles potential errors gracefully by falling back to a simple method.
