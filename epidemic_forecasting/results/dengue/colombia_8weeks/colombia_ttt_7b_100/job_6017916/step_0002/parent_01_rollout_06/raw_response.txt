```python
import numpy as np
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import matplotlib.pyplot as plt

def dengue_forecast(train_values, horizon, **kwargs):
    # Initialize the forecast array with zeros
    forecast = np.zeros((horizon, train_values.shape[1]))
    
    # Iterate over each region
    for i in range(train_values.shape[1]):
        try:
            # Check for missing values at the end of the training data
            if np.isnan(train_values[-1, i]):
                # If there are missing values, use a simple moving average forecast
                window_size = 5  # Define the window size for moving average
                moving_avg = np.convolve(train_values[:len(train_values)-window_size, i], np.ones(window_size)/window_size, mode='valid')
                forecast[:len(moving_avg), i] = moving_avg
                # Fill remaining forecasts with the last available value
                forecast[len(moving_avg):, i] = train_values[-window_size, i]
            else:
                # Fit an ARIMA model to the time series data
                model = ARIMA(train_values[:, i], order=(1, 1, 1))
                results = model.fit()
                # Forecast the next 'horizon' steps
                forecast[:, i] = results.forecast(steps=horizon)
        except Exception as e:
            # If fitting fails, use a constant forecast based on the last observed value
            forecast[:, i] = train_values[-1, i]
    
    # Ensure the forecast is non-negative
    forecast = np.maximum(forecast, 0)
    
    return forecast
```

### Explanation:
1. **Initialization**: The function initializes a forecast array filled with zeros.
2. **Region-wise Forecasting**:
   - For each region, it checks for missing values at the end of the training data.
   - If there are missing values, it uses a simple moving average (SMA) to forecast the next values. This helps in handling sparse or incomplete data.
   - If there are no missing values, it fits an ARIMA model to the historical data and uses it to forecast the next `horizon` steps.
3. **Exception Handling**: If fitting the model fails due to exceptions, it falls back to a constant forecast based on the last observed value.
4. **Non-Negative Constraint**: Finally, it ensures that all forecasted values are non-negative using `np.maximum(forecast, 0)`.

This approach ensures that the forecast is both accurate and robust against various scenarios, including missing data and model fitting failures.
