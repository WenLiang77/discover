```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.tsa.holtwinters import ExponentialSmoothing

def dengue_forecast(train_values, horizon, **kwargs):
    num_regions = train_values.shape[1]
    forecasted_values = np.zeros((horizon, num_regions), dtype=float)
    
    for region in range(num_regions):
        region_data = train_values[:, region]
        
        # Check for differencing needed based on variance comparison
        diff_order = 0
        if len(region_data) > 1 and np.diff(region_data).var() > 0.01 * region_data.var():
            diff_order = 1
        
        try:
            # Fit SARIMAX model with possible differencing
            model = SARIMAX(region_data, order=(1, diff_order, 1), seasonal_order=(1, 0, 1, 52)).fit(disp=False)
        except Exception as e:
            # If fitting fails, try Exponential Smoothing
            model = ExponentialSmoothing(region_data, trend='add', seasonal='add', seasonal_periods=52).fit(disp=False)
        
        # Get forecasted values
        forecasted_region_data = model.forecast(steps=horizon)
        
        # Ensure forecasted values are non-negative
        forecasted_values[:, region] = np.maximum(forecasted_region_data, 0)
    
    return forecasted_values
```

### Explanation:
1. **Initialization**: We initialize an array `forecasted_values` to store the forecasts for each region over the specified horizon.
2. **Region-wise Processing**: For each region, we process the time series data.
   - **Differencing Check**: We check if differencing is needed by comparing the variance of the differences with a fraction of the variance of the original data. This helps in handling non-stationary time series.
   - **Model Fitting**: We attempt to fit a SARIMAX model to the region's data. If fitting fails (e.g., due to insufficient data or other issues), we fall back to Exponential Smoothing.
   - **Forecasting**: We get the forecasted values from the model and ensure they are non-negative using `np.maximum`.
3. **Output**: Finally, we return the forecasted values array.

This approach ensures that the forecast is both temporally evolving and non-negative, which is crucial for dengue incidence data.
