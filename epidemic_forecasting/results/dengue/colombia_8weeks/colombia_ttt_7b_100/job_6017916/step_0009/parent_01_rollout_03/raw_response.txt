```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.tsa.holtwinters import ExponentialSmoothing

def dengue_forecast(train_values, horizon, **kwargs):
    num_regions = train_values.shape[1]
    forecasted_values = np.zeros((horizon, num_regions), dtype=float)
    
    for region in range(num_regions):
        region_data = train_values[:, region]
        
        # Check for differencing
        diff_order = 0
        if np.std(np.diff(region_data)) > 0.01 * np.std(region_data):
            diff_order = 1
        
        # Fit SARIMAX model
        try:
            model = SARIMAX(region_data, order=(1, diff_order, 1), seasonal_order=(1, 0, 1, 52)).fit(disp=False)
        except Exception as e:
            # If SARIMAX fails, try exponential smoothing
            model = ExponentialSmoothing(region_data, trend='add', seasonal='add', seasonal_periods=52).fit(disp=False)
        
        # Get forecast and clip negative values
        forecasted_region_data = model.forecast(steps=horizon)
        forecasted_region_data = np.maximum(forecasted_region_data, 0)
        
        # Store forecasted values
        forecasted_values[:, region] = forecasted_region_data
    
    return forecasted_values
```

### Explanation:
1. **Initialization**: We initialize an array `forecasted_values` of zeros with shape `(horizon, num_regions)` to store the forecasted values.
2. **Loop through Regions**: For each region, we extract the historical data.
3. **Differencing Check**: We check if differencing is needed based on the standard deviation of the differences.
4. **Model Fitting**:
   - We attempt to fit a `SARIMAX` model. If this fails (due to exceptions like convergence issues), we fall back to `Exponential Smoothing`.
5. **Forecasting**: We get the forecasted values and ensure they are non-negative by clipping any negative values to zero.
6. **Store Forecasts**: We store the forecasted values for each region in the `forecasted_values` array.

This approach ensures that the forecast models the temporal evolution of the dengue incidence data effectively and handles potential model fitting failures gracefully.
