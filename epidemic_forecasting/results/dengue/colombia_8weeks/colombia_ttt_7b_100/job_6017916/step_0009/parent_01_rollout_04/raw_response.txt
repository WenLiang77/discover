```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.tsa.holtwinters import ExponentialSmoothing

def dengue_forecast(train_values, horizon, **kwargs):
    num_regions = train_values.shape[1]
    forecasted_values = np.zeros((horizon, num_regions), dtype=float)
    
    for region in range(num_regions):
        region_data = train_values[:, region]
        
        # Determine differencing order based on variance
        diff_order = 0
        if np.diff(region_data).var() > 0.01 * region_data.var():
            diff_order = 1
        
        # Fit SARIMAX model if possible, otherwise use Exponential Smoothing
        try:
            model = SARIMAX(region_data, order=(1, diff_order, 1), seasonal_order=(1, 0, 1, 52)).fit(disp=False)
        except Exception as e:
            model = ExponentialSmoothing(region_data, trend='add', seasonal='add', seasonal_periods=52).fit(disp=False)
        
        # Get forecasted values and ensure they are non-negative
        forecasted_region_data = model.get_forecast(steps=horizon).predicted_mean
        forecasted_values[:, region] = forecasted_region_data.clip(0)
    
    return forecasted_values
```

This implementation fits either a SARIMAX model or an Exponential Smoothing model to each region's historical dengue case count data. The choice between models is based on whether differencing is needed to stabilize the time series. The forecasted values are then clipped to ensure they are non-negative before being returned. This approach ensures that the forecast adheres to the requirements and handles both stationary and non-stationary time series effectively.
