import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    num_regions = train_values.shape[1]
    forecasted_values = np.zeros((horizon, num_regions), dtype=float)
    
    for region in range(num_regions):
        region_data = train_values[:, region]
        
        # Determine differencing order based on variance
        diff_order = 0
        if np.diff(region_data).var() > 0.01 * region_data.var():
            diff_order = 1
        
        # Fit SARIMAX model
        try:
            model = SARIMAX(region_data, order=(1, diff_order, 1), seasonal_order=(1, 0, 1, 52)).fit(disp=False)
            forecasted_region_data = model.get_forecast(steps=horizon).predicted_mean

This implementation uses a combination of SARIMAX and Exponential Smoothing to forecast dengue incidence across multiple regions. The choice between these models is determined based on the variance of the differences in the time series. If the variance is above a certain threshold, a SARIMAX model is used; otherwise, an Exponential Smoothing model is employed. Both models are trained on the historical data and used to forecast the specified horizon. The forecasted values are clipped to ensure they are non-negative. This approach ensures that the forecast incorporates both trend and seasonal components while handling potential model fitting issues gracefully.
