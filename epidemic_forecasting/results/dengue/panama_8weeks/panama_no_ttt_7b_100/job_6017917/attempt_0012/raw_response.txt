```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    num_regions = train_values.shape[1]
    forecast = np.zeros((horizon, num_regions))
    
    for region in range(num_regions):
        # Fit a SARIMA model to each region's time series
        try:
            model = SARIMAX(train_values[:, region], order=(1, 1, 1), seasonal_order=(1, 1, 1, 52))
            results = model.fit(disp=False)
            
            # Generate forecasts for the specified horizon
            forecast[:, region] = results.forecast(steps=horizon)
        except Exception as e:
            # If fitting fails, use a simple moving average as a fallback
            window_size = min(52, len(train_values))  # Use at most half a year of data
            rolling_mean = np.convolve(train_values[:, region], np.ones(window_size)/window_size, mode='valid')
            forecast[:len(rolling_mean), region] = rolling_mean
            
            # Pad the remaining forecasts with the last observed value
            if horizon > len(rolling_mean):
                forecast[len(rolling_mean):, region] = train_values[-1, region]
    
    return np.clip(forecast, 0, None)  # Ensure all values are non-negative
```

This implementation fits a Seasonal AutoRegressive Integrated Moving Average (SARIMA) model to each region's dengue case-count time series. The model is designed to capture both temporal dependencies and seasonality typical of weekly dengue cases. If fitting the SARIMA model fails for any reason, it falls back to using a simple moving average, which provides some level of smoothing but avoids making arbitrary assumptions about the underlying time series dynamics. The forecast is then clipped to ensure all values are non-negative, as required.
