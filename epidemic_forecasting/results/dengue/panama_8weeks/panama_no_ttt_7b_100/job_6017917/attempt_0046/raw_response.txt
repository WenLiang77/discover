```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline
from sklearn.metrics import mean_absolute_error, mean_squared_error

def dengue_forecast(train_values, horizon, **kwargs):
    n_regions = train_values.shape[1]
    forecast = np.zeros((horizon, n_regions))
    
    for region in range(n_regions):
        region_data = train_values[:, region].reshape(-1, 1)
        
        # Check if the region's data is constant or nearly constant
        if np.all(region_data == region_data[0]):
            forecast[:, region] = region_data[0]
            continue
        
        # Fit a polynomial regression model up to degree 3
        model = make_pipeline(PolynomialFeatures(degree=3), LinearRegression())
        model.fit(np.arange(len(region_data)).reshape(-1, 1), region_data)
        
        # Predict the next 'horizon' steps
        future_steps = np.arange(len(region_data), len(region_data) + horizon).reshape(-1, 1)
        forecast[:, region] = np.clip(model.predict(future_steps), 0, None)
    
    return forecast
```

This forecasting algorithm fits a polynomial regression model of degree 3 to each region's historical dengue case-counts. If the historical data is constant or nearly constant, it predicts a constant value for the forecast horizon. Otherwise, it uses the fitted model to predict the next `horizon` steps. The forecast is clipped to non-negative values to ensure feasibility. This approach aims to capture temporal variations while handling sparse and potentially non-stationary series.
