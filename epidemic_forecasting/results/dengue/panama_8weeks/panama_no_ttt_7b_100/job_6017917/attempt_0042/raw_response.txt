```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    T, N = train_values.shape
    
    # Initialize the forecast array with zeros
    forecast = np.zeros((horizon, N))
    
    for i in range(N):
        try:
            # Fit a SARIMAX model to the historical data for each region
            model = SARIMAX(train_values[:, i], order=(1, 1, 0), seasonal_order=(1, 1, 0, 52))
            results = model.fit(disp=False)
            
            # Make predictions for the future horizon
            forecast[:, i] = results.forecast(steps=horizon)
        except Exception as e:
            # If fitting fails, use a simple moving average as a fallback
            forecast[:, i] = np.convolve(train_values[:, i], np.ones(horizon)/horizon, mode='valid')
            forecast[:, i] = np.pad(forecast[:, i], (0, horizon - len(forecast[:, i])), 'constant', constant_values=forecast[-1, i])
    
    # Ensure the forecast is non-negative
    forecast = np.maximum(forecast, 0)
    
    return forecast
```

This implementation uses a Seasonal AutoRegressive Integrated Moving Average with eXogenous factors (SARIMAX) model from `statsmodels` to fit the historical data for each region. It then makes predictions for the specified horizon. If the fitting process fails for any region, a simple moving average is used as a fallback. The forecast is ensured to be non-negative before returning it.
