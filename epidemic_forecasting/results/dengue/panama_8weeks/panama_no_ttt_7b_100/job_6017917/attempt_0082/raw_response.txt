```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
from statsmodels.tsa.stattools import adfuller
from sklearn.metrics import mean_squared_error
from math import sqrt
import matplotlib.pyplot as plt

def dengue_forecast(train_values, horizon, **kwargs):
    # Initialize the forecast array with zeros
    forecast = np.zeros((horizon, train_values.shape[1]))
    
    # Loop through each region
    for i in range(train_values.shape[1]):
        # Extract the time series for the current region
        series = train_values[:, i]
        
        # Check if the series is stationary
        result = adfuller(series)
        if result[1] > 0.05:
            # If not stationary, difference the series
            series_diff = np.diff(series)
            series_diff = np.append(series_diff, [np.nan])
        else:
            series_diff = series
        
        # Fit a SARIMA model to the differenced series
        try:
            model = SARIMAX(series_diff[:-1], order=(1, 1, 1), seasonal_order=(1, 1, 1, 4))
            results = model.fit(disp=False)
            
            # Forecast the next 'horizon' steps
            forecast_steps = horizon + len(series_diff)
            forecast_series_diff = results.forecast(steps=forecast_steps)[-horizon:]
            
            # Integrate back to get the forecast for the original series
            forecast[i] = np.cumsum(forecast_series_diff)
            forecast[i][0] = series[-1]  # Set the first forecasted value to the last observed value
            
            # Ensure the forecast is non-negative
            forecast[i] = np.maximum(forecast[i], 0)
        except Exception as e:
            # If fitting fails, use a simple moving average as a fallback
            forecast[i] = np.convolve(series, np.ones(horizon)/horizon, mode='valid')
            forecast[i] = np.pad(forecast[i], (0, horizon - len(forecast[i])), 'constant', constant_values=(0, 0))
            forecast[i] = np.maximum(forecast[i], 0)
    
    return forecast
```

### Explanation:
1. **Initialization**: The forecast array is initialized with zeros.
2. **Stationarity Check**: For each region, we check if the time series is stationary using the Augmented Dickey-Fuller test. If it's not stationary, we difference the series.
3. **SARIMA Model Fitting**: We fit a Seasonal AutoRegressive Integrated Moving Average (SARIMA) model to the differenced series. The parameters `(1, 1, 1)` and `(1, 1, 1, 4)` are chosen based on common defaults for weekly data.
4. **Forecasting**: We forecast the next `horizon` steps and then integrate back to get the forecast for the original series.
5. **Non-Negative Constraint**: We ensure that the forecast values are non-negative.
6. **Fallback Mechanism**: If the model fitting fails, we use a simple moving average as a fallback.

This approach ensures that the forecast models temporal evolution and handles potential issues like stationarity and non-negativity constraints.
