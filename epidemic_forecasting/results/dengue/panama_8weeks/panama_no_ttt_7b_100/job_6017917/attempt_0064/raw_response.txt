```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    n_regions = train_values.shape[1]
    forecast = np.zeros((horizon, n_regions))
    
    for region in range(n_regions):
        # Fit a SARIMAX model to the historical data for each region
        try:
            model = SARIMAX(train_values[:, region], order=(1, 1, 1), seasonal_order=(1, 1, 1, 52))
            result = model.fit(disp=False)
            forecast[:horizon, region] = result.forecast(steps=horizon)
        except Exception as e:
            # If fitting fails, use a simple moving average as a fallback
            forecast[:horizon, region] = np.convolve(train_values[:, region], np.ones(horizon)/horizon, mode='valid')
    
    # Ensure the forecast is non-negative
    forecast = np.maximum(forecast, 0)
    
    return forecast
```

This implementation uses the SARIMAX model from `statsmodels.tsa` to fit a time-series model to each region's historical data. It then forecasts the next `horizon` weeks for each region. If fitting the model fails (e.g., due to insufficient data or other issues), it falls back to using a simple moving average. The forecast is ensured to be non-negative.
