```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    # Initialize the forecast array with zeros
    forecast = np.zeros((horizon, train_values.shape[1]))
    
    # Loop over each region (column) in the training data
    for i in range(train_values.shape[1]):
        # Extract the time series for the current region
        ts = train_values[:, i]
        
        try:
            # Fit a SARIMAX model to the time series
            model = SARIMAX(ts, order=(1, 1, 1), seasonal_order=(1, 1, 1, 52))
            results = model.fit(disp=False)
            
            # Generate forecasts for the specified horizon
            forecast[:, i] = results.forecast(steps=horizon)
        except Exception as e:
            # If fitting fails, fill the forecast with the last observed value
            forecast[:, i] = ts[-1] if len(ts) > 0 else 0
    
    # Ensure the forecast is non-negative
    forecast = np.maximum(forecast, 0)
    
    return forecast
```

This forecasting algorithm uses the Seasonal AutoRegressive Integrated Moving Average with eXogenous factors (SARIMAX) model from the `statsmodels` library to fit each region's dengue case count time series. The model captures both temporal trends and seasonality. For each region, the algorithm attempts to fit the model and generates forecasts for the specified horizon. If fitting fails due to exceptions (e.g., insufficient data, convergence issues), the algorithm falls back to predicting a constant value based on the last observed value. Finally, the forecasted values are clipped to ensure they are non-negative before being returned.
