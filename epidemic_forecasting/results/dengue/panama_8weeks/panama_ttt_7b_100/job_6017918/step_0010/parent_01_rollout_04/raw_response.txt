```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    for i in range(train_values.shape[1]):
        try:
            # Ensure positive values by handling zeros and negatives
            train_values[:, i] = np.where(train_values[:, i] <= 0, np.nan, train_values[:, i])
            
            # Fit SARIMAX model to capture temporal patterns and seasonality
            model = SARIMAX(train_values[:, i], order=(1, 1, 0), seasonal_order=(1, 1, 0, 4), enforce_stationarity=False, enforce_invertibility=False)
            results = model.fit(disp=False)
            
            # Get forecasted values
            forecast[:, i] = results.get_forecast(steps=horizon).predicted_mean
            
            # Ensure non-negative forecasts
            forecast[:, i] = np.maximum(forecast[:, i], 0)
        except Exception as e:
            # Fallback to simple linear regression if model fitting fails
            if np.all(np.isnan(train_values[:, i])):
                regional_means = np.nanmean(train_values[:, train_values[:, i] > 0], axis=1)
                forecast[:, i] = np.interp(range(horizon), [0, len(regional_means) - 1], regional_means)
            else:
                forecast[:, i] = np.polyval(np.polyfit(np.arange(len(train_values)), train_values[:, i], 1), np.arange(len(train_values), len(train_values) + horizon))
    
    return forecast
```

This implementation uses the SARIMAX model from `statsmodels` to fit the historical dengue case counts and generate forecasts. If the model fitting fails due to issues like stationarity constraints or other errors, it falls back to a simple linear regression model. This ensures that the forecast remains non-negative and has the required shape.
