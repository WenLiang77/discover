```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import matplotlib.pyplot as plt
from sklearn.metrics import mean_absolute_error, mean_squared_error, symmetric_mean_absolute_percentage_error
from statsmodels.tsa.stattools import adfuller
import pandas as pd

def check_stationarity(timeseries):
    result = adfuller(timeseries)
    if result[1] <= 0.05:
        return True
    else:
        return False

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    for i in range(train_values.shape[1]):
        try:
            # Check stationarity and determine parameters
            if check_stationarity(train_values[:, i]):
                order = (1, 0, 0)
                seasonal_order = (0, 1, 0, 4)
            else:
                order = (1, 1, 0)
                seasonal_order = (1, 1, 0, 4)
            
            # Fit SARIMAX model
            model = SARIMAX(train_values[:, i], order=order, seasonal_order=seasonal_order)
            results = model.fit(disp=False)
            
            # Forecast
            forecast[:, i] = results.forecast(steps=horizon)
        except Exception as e:
            # If fitting fails, use simple exponential smoothing as a fallback
            alpha = 0.2
            forecast[:, i] = np.convolve(train_values[:, i], [alpha]*(1+int(1/alpha)), mode='valid')[-horizon:]
    
    forecast = np.maximum(forecast, 0)
    return forecast
```

### Explanation:
1. **Stationarity Check**: The `check_stationarity` function uses the Augmented Dickey-Fuller test to determine if the time series is stationary.
2. **Model Parameters**: Depending on whether the series is stationary, different parameter sets (`order` and `seasonal_order`) are chosen for the SARIMAX model.
3. **Fitting and Forecasting**:
   - For each region, the SARIMAX model is fit.
   - The forecast is generated for the specified horizon.
4. **Fallback Mechanism**: If fitting the model fails due to exceptions (e.g., convergence issues), a simple exponential smoothing approach is used as a fallback.
5. **Non-Negative Forecasts**: The forecasted values are clipped to ensure they are non-negative.

This approach ensures that the forecasts are robust to various types of time series characteristics and provides a baseline for comparison with more complex models.
