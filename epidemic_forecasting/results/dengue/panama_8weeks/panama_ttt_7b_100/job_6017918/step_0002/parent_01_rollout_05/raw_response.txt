```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.tsa.holtwinters import ExponentialSmoothing
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import matplotlib.pyplot as plt

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    
    for i in range(train_values.shape[1]):
        try:
            # Check for stationarity and determine model parameters
            acf_vals = plot_acf(train_values[:, i], lags=20, ax=None)
            pacf_vals = plot_pacf(train_values[:, i], lags=20, ax=None)
            
            # Fit ARIMA model
            arima_model = ARIMA(train_values[:, i], order=(1, 1, 0))
            arima_results = arima_model.fit()
            
            # Fit SARIMAX model if ARIMA does not work well
            sarimax_model = SARIMAX(train_values[:, i], order=(1, 1, 0), seasonal_order=(1, 1, 0, 4))
            sarimax_results = sarimax_model.fit(disp=False)
            
            # Combine forecasts from both models
            arima_forecast = arima_results.forecast(steps=horizon)
            sarimax_forecast = sarimax_results.forecast(steps=horizon)
            
            # Average the forecasts
            combined_forecast = (arima_forecast + sarimax_forecast) / 2
            
            # Ensure non-negativity
            combined_forecast = np.maximum(combined_forecast, 0)
            
            forecast[:, i] = combined_forecast
        
        except Exception as e:
            # Fallback to simple exponential smoothing if all else fails
            es_model = ExponentialSmoothing(train_values[:, i], trend='add', seasonal='multiplicative')
            es_results = es_model.fit(disp=False)
            forecast[:, i] = es_results.forecast(steps=horizon)
    
    return forecast
```

### Explanation:

1. **ARIMA Model**: We first attempt to fit an ARIMA model to each region's time series. ARIMA is good at capturing linear trends and seasonality.

2. **SARIMAX Model**: If the ARIMA model fails to converge or perform well, we switch to a SARIMAX model. SARIMAX extends ARIMA to include seasonal components, which can help in modeling periodic patterns.

3. **Combining Forecasts**: We combine the forecasts from both models to potentially improve performance. This averaging approach helps in reducing bias and variance.

4. **Exponential Smoothing Fallback**: If both ARIMA and SARIMAX fail, we fall back to simple exponential smoothing. This is a basic but effective method for handling non-stationary time series.

5. **Non-Negativity Constraint**: We ensure that the forecasted values are non-negative by applying the `np.maximum` function.

This approach aims to provide a robust and versatile forecasting model that can handle various types of dengue incidence data, including those with temporal variations, noise, and potential stationarity issues.
