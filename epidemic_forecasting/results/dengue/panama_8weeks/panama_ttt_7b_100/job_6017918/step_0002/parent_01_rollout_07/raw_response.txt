```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    for i in range(train_values.shape[1]):
        try:
            # Fit a SARIMAX model to the historical data for each region
            model = SARIMAX(train_values[:, i], order=(1, 1, 0), seasonal_order=(1, 1, 0, 4))
            results = model.fit(disp=False)
            # Forecast the next `horizon` steps for the current region
            forecast[:, i] = results.forecast(steps=horizon)
        except Exception as e:
            # If fitting fails, use the most recent observation as a fallback
            forecast[:, i] = train_values[-1, i]
    
    # Ensure the forecast is non-negative
    forecast = np.maximum(forecast, 0)
    return forecast
```

### Explanation:
1. **Model Definition**: The function defines a `SARIMAX` model, which is suitable for time series with both trend and seasonality components.
2. **Fitting Loop**: For each region, the model attempts to fit a `SARIMAX` model to the historical data.
3. **Forecasting**: Once the model is fitted, it forecasts the next `horizon` steps for that region.
4. **Fallback Mechanism**: If the model fitting fails due to any exception, the function falls back to using the most recent observed value for that region.
5. **Non-Negative Constraint**: The forecast is clipped to ensure it does not contain negative values.

This approach ensures that the forecast is non-negative and models temporal evolution, adhering to the requirements specified.
