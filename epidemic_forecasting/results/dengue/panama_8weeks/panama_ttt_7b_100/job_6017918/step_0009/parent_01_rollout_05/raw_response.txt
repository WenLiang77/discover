from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):

### Explanation:
1. **Data Preprocessing**:
   - The function iterates over each region's time series.
   - Non-positive values in the training data are replaced with NaNs to handle zero-inflated series.
   
2. **Model Fitting**:
   - A `SARIMAX` model is fit to the historical data for each region.
   - The model parameters `(1, 1, 0)` and seasonal parameters `(1, 1, 0, 4)` are chosen based on typical characteristics of time series forecasting.
   - The model is fit without enforcing stationarity to allow for more flexibility in capturing trends and seasonality.
   
3. **Forecast Generation**:
   - If the model fitting succeeds, the forecasted values are obtained using `results.get_forecast(steps=horizon).predicted_mean`.
   - If the model fitting fails due to issues like convergence problems or other exceptions, a simple linear regression model is used as a fallback.
   - Linear regression is applied on scaled data (`X_train_scaled` and `y_train_scaled`) to ensure better performance on non-stationary and noisy series.
   
4. **Output Handling**:
   - The forecasted values are clipped to ensure they are non-negative before being returned.
   - The function ensures the returned forecast has the correct shape `(horizon, N)`.

This approach aims to provide a robust and flexible solution that can handle various types of time series data while ensuring non-negativity and the required shape of the output.
