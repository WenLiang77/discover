```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    for i in range(train_values.shape[1]):
        try:
            # Ensure non-positive values are handled gracefully
            if np.any(train_values[:, i] <= 0):
                train_values[:, i] = np.where(train_values[:, i] <= 0, np.nan, train_values[:, i])
            
            # Fit SARIMAX model
            model = SARIMAX(train_values[:, i], order=(1, 1, 0), seasonal_order=(1, 1, 0, 4), enforce_stationarity=False, enforce_invertibility=False)
            results = model.fit(disp=False)
            
            # Get forecasted values
            forecast[:, i] = results.get_forecast(steps=horizon).predicted_mean
            
            # Clip negative forecasts to zero
            forecast[:, i] = np.maximum(forecast[:, i], 0)
        except Exception as e:
            # Fallback to linear regression if SARIMAX fails
            scaler = np.std(train_values[:, i]) if np.std(train_values[:, i]) != 0 else 1e-6
            X_train = np.arange(len(train_values)).reshape(-1, 1)
            y_train = train_values[:, i].reshape(-1, 1)
            slope = np.dot((X_train - np.mean(X_train)), (y_train - np.mean(y_train))) / ((X_train - np.mean(X_train))**2).sum()
            intercept = np.mean(y_train) - slope * np.mean(X_train)
            X_forecast = np.arange(len(train_values), len(train_values) + horizon).reshape(-1, 1)
            forecast[:, i] = slope * X_forecast + intercept
            
            # Ensure non-negative forecasts
            forecast[:, i] = np.maximum(forecast[:, i], 0)
    
    return forecast
```

### Explanation:
1. **Handling Non-Positive Values**: Any non-positive values in the training data are converted to NaN to handle them gracefully during modeling.
2. **SARIMAX Model**: A Seasonal AutoRegressive Integrated Moving Average with eXogenous factors (SARIMAX) model is used to capture both temporal and seasonal patterns in the time series.
3. **Forecasting**: The model's forecast method is called to predict the next `horizon` steps.
4. **Fallback Mechanism**: If fitting the SARIMAX model fails (due to exceptions), a simple linear regression model is used as a fallback. This ensures that even if complex models fail, some form of prediction is made.
5. **Negative Forecasts Handling**: All predicted values are clipped to ensure they are non-negative.

This approach ensures that the forecast is robust to various types of time series characteristics and handles potential failures in more complex models gracefully.
