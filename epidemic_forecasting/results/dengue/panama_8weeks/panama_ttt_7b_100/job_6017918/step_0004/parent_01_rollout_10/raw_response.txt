```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    for i in range(train_values.shape[1]):
        try:
            # Fit a SARIMAX model to each region's time series
            model = SARIMAX(train_values[:, i], order=(1, 1, 0), seasonal_order=(1, 1, 0, 4))
            results = model.fit(disp=False)
            
            # Forecast the next 'horizon' steps
            forecast[:, i] = results.get_forecast(steps=horizon).predicted_mean
            
            # Ensure forecasts are non-negative
            forecast[:, i] = np.maximum(forecast[:, i], 0)
        except Exception as e:
            # Fallback to the last observed value if model fitting fails
            forecast[:, i] = train_values[-1, i]
    
    return forecast
```

This implementation uses a Seasonal AutoRegressive Integrated Moving Average with eXogenous factors (SARIMAX) model from the `statsmodels` library to fit each region's time series and make forecasts. The model accounts for both temporal trends and seasonal patterns, which are typical characteristics of dengue incidence data. If the model fitting fails due to issues like non-positive endog data or negative indices, the forecast defaults to the last observed value for that region. This ensures that the forecast is always non-negative and has the correct shape.
