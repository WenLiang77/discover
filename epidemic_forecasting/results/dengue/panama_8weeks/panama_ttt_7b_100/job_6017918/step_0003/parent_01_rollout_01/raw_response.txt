```python
import numpy as np
from statsmodels.tsa.arima.model import ARIMA

def dengue_forecast(train_values, horizon, **kwargs):
    """
    Forecast Dengue incidence using an ARIMA model for each region.
    
    Parameters:
        train_values (np.ndarray): Historical dengue incidence data with shape (T, N).
        horizon (int): Number of future time steps to predict.
        kwargs: Additional keyword arguments (not used).
        
    Returns:
        np.ndarray: Forecasted dengue incidence data with shape (horizon, N).
    """
    num_regions = train_values.shape[1]
    forecasted_values = np.zeros((horizon, num_regions))
    for region in range(num_regions):
        try:
            # Fit an ARIMA model to the training data for the current region
            model = ARIMA(train_values[:, region], order=(2, 1, 0))
            model_fit = model.fit()
            # Generate forecasts for the specified horizon
            forecast = model_fit.forecast(steps=horizon)
            # Ensure forecasts are non-negative
            forecasted_values[:, region] = np.maximum(forecast, 0)
        except Exception as e:
            # If model fitting fails, use a simple moving average forecast
            rolling_mean = np.convolve(train_values[:, region], np.ones(horizon) / horizon, mode='same')
            # Clip negative values to zero
            forecasted_values[:, region] = np.maximum(rolling_mean, 0)
    return forecasted_values
```

This implementation uses an ARIMA model to forecast Dengue incidence for each region in the input data. The ARIMA model is fitted to the historical data for each region, and then used to generate forecasts for the specified horizon. If the model fitting fails, a simple moving average forecast is used instead. This approach ensures that the forecast is non-negative and has the required shape.
