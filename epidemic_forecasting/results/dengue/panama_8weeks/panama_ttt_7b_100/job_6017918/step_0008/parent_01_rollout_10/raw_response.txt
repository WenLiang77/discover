```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

def dengue_forecast(train_values, horizon, **kwargs):
    forecast = np.zeros((horizon, train_values.shape[1]))
    
    for i in range(train_values.shape[1]):
        try:
            # Replace non-positive values with NaNs
            train_values[:, i] = np.where(train_values[:, i] <= 0, np.nan, train_values[:, i])
            
            # Fit a SARIMAX model
            model = SARIMAX(train_values[:, i], order=(1, 1, 0), seasonal_order=(1, 1, 0, 4), enforce_stationarity=False, enforce_invertibility=False)
            results = model.fit(disp=False)
            
            # Get forecasted values
            forecast[:, i] = results.get_forecast(steps=horizon).predicted_mean
            
            # Ensure non-negative forecasts
            forecast[:, i] = np.maximum(forecast[:, i], 0)
        except Exception as e:
            # If fitting fails, use a simple linear regression model
            if np.all(np.isnan(train_values[:, i])):
                regional_means = np.nanmean(train_values[:, train_values[:, i] > 0], axis=1)
                forecast[:, i] = np.interp(range(horizon), [0, len(regional_means) - 1], regional_means)
            else:
                # Perform linear regression on scaled data
                scaler = StandardScaler()
                X_train = np.arange(len(train_values)).reshape(-1, 1)
                y_train = train_values[:, i].reshape(-1, 1)
                scaler.fit(X_train)
                X_train_scaled = scaler.transform(X_train)
                y_train_scaled = scaler.transform(y_train)
                
                lin_reg = LinearRegression()
                lin_reg.fit(X_train_scaled, y_train_scaled)
                
                X_forecast = np.arange(len(train_values), len(train_values) + horizon).reshape(-1, 1)
                X_forecast_scaled = scaler.transform(X_forecast)
                
                forecast_scaled = lin_reg.predict(X_forecast_scaled)
                forecast[:, i] = scaler.inverse_transform(forecast_scaled)
                
                # Ensure non-negative forecasts
                forecast[:, i] = np.maximum(forecast[:, i], 0)
    
    return forecast
```

### Explanation:
1. **Handling Non-positive Values**: The code replaces any non-positive values in the training data with NaNs to handle potential issues related to logarithmic transformations or other models that might not handle zeros or negatives well.
2. **SARIMAX Model**: For each region, a SARIMAX model is fit to capture both trend and seasonal components. This model is chosen because it can effectively handle time series with multiple seasonal patterns.
3. **Fallback Mechanism**: If the SARIMAX model fails to fit (e.g., due to insufficient data or instability), a simple linear regression model is used. This ensures that even in challenging scenarios, some form of prediction is made.
4. **Non-negativity**: The forecasted values are clipped to ensure they are non-negative, which is crucial for cases where negative values are not physically meaningful (e.g., disease counts).

This approach aims to provide a robust and flexible forecasting mechanism that handles various characteristics of dengue case data, including temporal evolution, seasonality, and sparsity.
