You are an expert in infectious disease modelling, epidemic forecasting, and multivariate time-series analysis.

Your task is to develop a novel forecasting algorithm for multivariate COVID-19 incidence time-series data.

## Problem

COVID-19 case-count time series are noisy, non-stationary, zero-inflated, and affected by reporting delays, changing interventions, and sudden epidemic waves.

Given historical multivariate COVID-19 incidence data from multiple regions, your task is to predict future COVID-19 incidence for every region over a specified forecasting horizon.

The objective is to design a forecasting algorithm that produces accurate, robust, non-negative, and computationally efficient forecasts while generalizing across different countries, regions, and epidemic stages.

The algorithm should outperform standard forecasting baselines without overfitting to the most recent observations.

--------------------------------------------------

## Data Format

The input variable `train_values` is a numpy array with shape `(T, N)`, where `T` is the number of historical time steps and `N` is the number of geographical regions or time series.

All values in `train_values` are non-negative COVID-19 incidence counts.

The input variable `horizon` is an integer representing the number of future time steps to forecast.

For daily COVID-19 datasets, the short-term forecasting horizon is 7 days, the medium-term forecasting horizon is 14 days, and the long-term forecasting horizon is 30 days.

The function should return a numpy array with shape `(horizon, N)`, containing the predicted COVID-19 incidence counts for every region.

All forecast values must be finite and non-negative.

--------------------------------------------------

## Evaluation

The predictions are evaluated against held-out future observations.

The evaluator automatically splits the data into training data and held-out future data. The algorithm only receives the training data and must forecast the future observations.

The following forecasting metrics are used:

- SMAPE: symmetric mean absolute percentage error
- MAE: mean absolute error
- RMSE: root mean squared error
- MASE: mean absolute scaled error

Lower values indicate better forecasting performance.

--------------------------------------------------

## Validity Constraints

A solution is rejected if the output shape is incorrect, if the output contains NaN or infinite values, if the output contains negative values, if the algorithm accesses future observations, if it performs filesystem or network I/O, or if it exceeds the runtime budget.

Only valid solutions are considered for scoring.

--------------------------------------------------

## Reward

Among valid solutions, lower forecasting error receives higher reward.

The main objective is to minimize forecasting error while keeping the method robust, stable, and computationally efficient.

A simple naive baseline repeats the most recent observed value for all future time steps. The proposed algorithm should aim to outperform this baseline by using recent trends, smoothing, transformations, lag information, and cross-region patterns.

--------------------------------------------------

## Time Budget

The maximum runtime is 400 seconds.

The algorithm should support CPU execution and avoid unnecessarily expensive optimization procedures.

The method should work on both small datasets such as `covid_uk.csv` and larger datasets such as `covid_us.csv`.

## Key Insights

COVID-19 incidence data often contains many zero values, so variance-stabilizing transformations such as `log1p` or square-root transformation may improve robustness.

Recent observations usually contain the strongest predictive signal, especially for short-term forecasting.

Simple persistence forecasting is often insufficient during epidemic growth or decline.

Regional epidemic trajectories may be correlated, so cross-region information may improve forecasting performance.

Moderate smoothing can reduce reporting noise, but excessive smoothing may hide sudden outbreak peaks.

Short-term forecasts should emphasize recent local trends, while medium-term and long-term forecasts should avoid unstable extrapolation.

Forecasts should remain finite, non-negative, and numerically stable.
