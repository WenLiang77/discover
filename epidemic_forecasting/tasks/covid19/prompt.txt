## Problem

The input `train_values` is a non-negative NumPy array with shape `(T, N)`, where `T` is the number of historical time steps and `N` is the number of geographical regions.

The input `horizon` is the number of future time steps to predict.

The held-out future observations are unavailable to the forecasting function and are used only by the evaluator.

## Evaluation

Valid predictions are scored using SMAPE, MAE, RMSE and MASE. Lower values are better. The scalar reward is derived from the primary forecasting error so that larger reward is better.

A candidate is invalid if it has the wrong output shape, contains non-finite or negative values, accesses files or the network, uses future observations, or exceeds the runtime budget.
